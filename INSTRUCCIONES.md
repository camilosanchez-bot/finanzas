# 🚀 MONEY-FLOW APP - INSTRUCCIONES RÁPIDAS

## ¡Hola! Aquí están tus opciones para usar la app:

### ✅ OPCIÓN 1: SIN INSTALACIÓN (MÁS FÁCIL)

1. Ve a la carpeta `moneyflow-app`
2. Busca el archivo `standalone.html`
3. Haz doble clic para abrirlo en tu navegador
4. ¡Listo! La app funciona sin necesidad de instalar nada

**Ventaja**: Funciona inmediatamente  
**Desventaja**: Versión simplificada (sin gráficos interactivos avanzados)

---

### 💻 OPCIÓN 2: CON NODE.JS (RECOMENDADO - VERSIÓN COMPLETA)

#### Paso 1: Instala Node.js (si no lo tienes)
- Ve a https://nodejs.org/
- Descarga e instala la versión LTS
- Reinicia tu computadora

#### Paso 2: Abre Terminal/CMD en la carpeta del proyecto
- En Windows: Haz clic derecho en la carpeta → "Abrir terminal aquí"
- En Mac: Usa Terminal.app y navega a la carpeta
- En Linux: Abre terminal en la carpeta

#### Paso 3: Instala dependencias
Copia y pega esto en la terminal:
```bash
npm install
```

Espera a que termine (puede tardar 1-2 minutos la primera vez)

#### Paso 4: Inicia la app
Copia y pega esto:
```bash
npm run dev
```

#### Paso 5: Abre en tu navegador
- Se abrirá automáticamente en `http://localhost:3000`
- Si no se abre, copia y pega esa dirección en tu navegador

**Ventaja**: Versión completa con todos los gráficos y funciones  
**Desventaja**: Requiere Node.js instalado

## 🎯 Cómo usar la app una vez abierta

1. **Ingresa tus datos** en el formulario inicial (gasto, años, rentabilidad, etc.)
2. **Dale a "Comenzar Plan"**
3. **Verás tu "Número Dorado"** (patrimonio necesario)
4. **Explora las 3 secciones**:
   - 📊 Las 3 Palancas (estrategia Money-Flow)
   - 📈 Mi Seguimiento (registra tus aportes)
   - 🔮 Proyecciones (gráficos de crecimiento)

---

## 💾 Tus datos se guardan localmente

- La app guarda todo en tu navegador
- No se envía a Internet
- Puedes cerrar y volver después, tus datos estarán ahí
- Si quieres borrar todo: Limpia el caché de tu navegador

---

## ❓ Problemas frecuentes

**"No me abre con Opción 1"**
- Asegúrate de tener Java Script habilitado en tu navegador
- Intenta con otro navegador (Chrome, Firefox, Safari)

**"No me funciona Opción 2"**
- Verifica que Node.js esté instalado: `node --version` en terminal
- Borra la carpeta `node_modules` y vuelve a hacer `npm install`

**"Los gráficos no aparecen"**
- Actualiza la página (F5)
- Cierra y abre de nuevo
